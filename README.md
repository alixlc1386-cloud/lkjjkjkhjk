# YASIN AI ADS — نسخه تحت Node.js

سامانه هوشمند مدیریت تبلیغات، ساخت محتوا با هوش مصنوعی و انتشار خودکار در پیام‌رسان بله (Bot API) با رابط کاربری نئونی، پس‌زمینه ذرات سه‌بعدی و مکعب چرخان.

## امکانات اصلی
- **دستیار هوش مصنوعی و فرمان صوتی**: پردازش متن یا صوت فارسی و تولید پیش‌نویس، انتشار آنی یا زمان‌بندی
- **انتشار خودکار و دستی**: اتصال به Bot API رسمی بله جهت ارسال پیام متنی یا تصاویر همراه کپشن
- **سیستم کاربران و نشست‌ها**: ثبت‌نام، ورود با شماره و رمز قوی (bcrypt)، محافظت CSRF
- **زمان‌بندی پست‌ها**: صف ارسال با اجرای دوره‌ای خودکار یا فراخوانی `/cron.php`
- **جلوه‌های سه‌بعدی**: رندر بوم متحرک (`canvas #bg3d`)، افکت‌های تراز کارت و مکعب CSS

## پیش‌فرض ورود جهت بررسی اولیه
- **شماره موبایل**: `09120000000`
- **رمز عبور**: `YasinAdmin1234!`
*(امکان ثبت‌نام آزاد کاربر جدید در صفحه ثبت‌نام نیز فراهم است)*

## متغیرهای محیطی
جهت اتصال هوش مصنوعی و ربات، می‌توانید مقادیر را در فایل `.env` یا مستقیماً از بخش تنظیمات پنل ثبت نمایید:
- `PORT=3000`
- `OPENAI_API_BASE=https://api.openai.com/v1`
- `OPENAI_API_KEY=`
- `BALE_BOT_TOKEN=`
